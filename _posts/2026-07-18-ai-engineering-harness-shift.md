一个最能概括的对照:Lilian Weng 2023 年写的是「agent 的解剖结构」,2026 年写的是「harness engineering」——她的关注点,从模型本身,移到了模型外面那一圈系统。

1️⃣ 重心从 agent 转向它周围的系统。今年会上几乎没人再提 AutoGPT,大家聊的是 Claude Code、Codex、Gemini CLI、Cursor、Warp 这些「底座」。单个 agent 聪不聪明,不如它跑在什么系统里重要。

2️⃣ Loop engineering 成了新的控制层。内环(inner loop)是直接干活、跟用户交互的那部分;外环(outer loop)负责编排、反馈、监督。人待在外环做判断,agent 在内环执行。谁把外环设计好,谁就握住了这套系统的方向盘。

3️⃣ AI 工程正式走进企业。开始出现「Forward Deployed Engineer」这种角色,专门把 AI 塞进企业流程里落地。Sierra 的人说,企业真正缺的那块,是把这些能力编排起来的能力。

4️⃣ Coding agent 正在取代 IDE,成为开发者的主界面。它能读懂目标、自己翻代码库、改文件、跑测试、再迭代——你面对的东西,从编辑器变成了一个会干活的 agent。

5️⃣ 每个 agent 平台都在围绕 skills 搭。skills 把「资深工程师怎么干活」——工作流、质量关卡、最佳实践——编码进去,让 agent 照着来,省得每次从零开始试。这也是为什么各家平台都在抢着做自己的 skill 生态。

💡 我的判断:这一年,拉开差距的能力已经很清楚——设计外环、立质量关卡、攒自己的 skill 库。prompt 谁都会写,系统才是新的分水岭。这是从「调模型」到「搭系统」的一个拐点,早看懂的人,占的是下一代 AI 原生应用的先发。让模型跑起来只是起点,让它可控、可迭代才算本事。
