OpenRouter 干的事一句话讲清楚:它是一个 API gateway,把 Anthropic、Google、OpenAI、xAI、DeepSeek 这 400 多个模型聚到一个端点。你的应用调一次,它后面挑哪个模型由你的 prompt + 价格 + 延迟 + 推理质量来决定。

🚀 关键数字 · 6 个月翻 5 倍

800 万全球用户 · 每月 100 万亿 token 在它后台跑过。半年前是每周 5 万亿 token,现在是每周 25 万亿。

为什么这条路忽然这么值钱?推理阶段的格局变了。客服任务给一家,代码给另一家,长 context summarization 给第三家——同一个 app 里每条调用的最优解都不同。OpenRouter 把这层 routing 外包给了一个独立中间层。

「企业不会再像 SaaS 时代那样,把自己锁死在一家厂商上。」💡 — 文章原话。

更深一层的信号:模型层的 commoditization 在加速。每多一家发新模型,中间层的议价权就涨一格。
