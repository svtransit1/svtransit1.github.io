挑出 4 个具体 vertical 的落地——

1. 税务 + 法律客户服务:接入 KPMG 自己的 Digital Gateway 平台。一个具体的数:过去内部「写一个新的税务法规调整 agent」要几周,现在用 Claude Cowork + Managed Agents,几分钟就能搭好上线。

2. 网络安全:漏洞检测 + 修复,从扫描出 CVE 到 patch 建议一条管线。

3. 代码现代化:KPMG Blaze 工具线,专门给被投资组合公司做 legacy codebase 翻新。

4. 内部业务流程现代化:KPMG 自己的运营 backend,从财务到 HR 都在重写。

为什么这事值得放下来想——

Sunday 我们贴过 roon(@tszzl,OpenAI)那条「模型本身不会卖出去」的帖子:他承认 Anthropic 在 vertical packaging 这块做得比 OpenAI 系统多。当时是 X 上的一句话评论,讨论度高但还停留在 commentary 层面。

这次 KPMG 的官宣,就是这条 commentary 落到具体合同上的样子——四大会计师事务所之一,全球 276K 员工,co-development 而不是单纯 license,Anthropic 标注 KPMG 为「preferred partner」。

不再是「Claude 在某家律所有用户」这种弱信号,是「四大之一全球部署」这种 enterprise-grade 信号。

更深一层:KPMG 这套体系最被低估的是 Digital Gateway 这个内部平台——它把 Claude 包装成「税务专家配置出新规则只需要描述需求,自己不写代码」的形态。这就是 vertical packaging 的工程实现:不是让税务专家学 prompt engineering,是让 Claude 学税务专家的工作流。

对在做企业 AI 部署的朋友——KPMG 这个案例值得做参考蓝图。对做 Claude 应用产品的朋友——Anthropic 在企业渠道的 motion 明显往「行业方案合作伙伴」走,从 API 销售转 SaaS-style 长期分成的味道越来越浓。

转给那个还在等「Claude 什么时候能真正进入企业」的朋友——它已经在路上,而且走得比想象中快。
