接入方式很直接: 你在 Robinhood 开一个 Agentic Account, 划一笔预算进去, 然后把这个账户的 MCP URL 粘到 agent config 里, agent 就可以分析行情、调仓、下单, 全程不需要你按确认。

CEO Vlad Tenev 一句话总结:「Agent, meet markets。」

Robinhood 自己的免责声明写得也很直接:

— 「Significant risk of total investment loss」

— Robinhood 不会监督、审计任何第三方 agent

— 你的数据交给 AI 提供商, 走的是对方的条款不是 Robinhood 的

— 「Not appropriate for all investors」

这事的份量超过单一产品: 第一家主流 retail broker 把 MCP 接口直接接到真账户。一旦跑通, fidelity、interactive brokers、charles schwab 跟进只是时间问题。

agent 现在已经能写 PR、跑代码、订机票, 接下来一年, 它能不能稳定地操盘股票, 是一道新的工程题。
