发这话的是 roon(@tszzl),OpenAI 的 research 圈里位置不低,平时发言谨慎。他这条 8 小时拿了 1.3K 赞、15 万浏览。

事情起源很小:他把一个资深律师朋友介绍给 GPT-5.5 pro,期待对方拿来用。结果没用起来。律师不是不懂 AI,是没法把「这个东西能做什么」对应到自己每天具体的活儿上——拟合同、研究判例、改 brief。

roon 想通的事:模型再强,客户也不会自己把它跟自己的工作流接起来。中间那块——「把通用能力包装成行业方案」——必须有人替客户做。

然后他点了 Anthropic 的名:Claude 这两年最被低估的一件事——把模型「打包成行业用例」这块做得比 OpenAI 系统多了。

这是 OpenAI 内部圈的人第一次公开点名说这条线对面做得更好。

为什么这件事值得放下来想——

过去两年 frontier 模型的竞争主轴是 capability:谁的 reasoning 强、谁的 coding 强、谁的 context 长。但终端市场早就过了「证明能做」的阶段,卡在「怎么用」这一关。一个律师 / 一个会计 / 一个保险核保员要的不是「再强 5 分的 IQ」,要的是「针对我这个工种的 workflow + 案例 + 模板」。

谁先把这层做厚,谁就能从 API 计价跳到 seat-based SaaS 计价。差别不是 2 倍,是 10 倍。

Anthropic 这两年的 vertical 打法看起来是有意识地在 build 一条不跟 OpenAI 拼裸 capability 的护城河。现在 OpenAI 内部的人也开始公开承认这条护城河起作用了。

转给那个还在「我们模型 benchmark 更高」叙事里的朋友——市场早不在那条赛道上了。
