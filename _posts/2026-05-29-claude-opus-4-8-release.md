Claude Opus 4.8 · 7 件事

1 · 代码 bug 漏检 ↓ 4×

4.7 漏掉的代码 bug, 4.8 平均要 4 倍才会再漏。代码审查侧的诚实度跳了一档。

2 · Legal Agent Benchmark 首破 10%

法律 agent 这条线, 全 pass 标准上, Opus 4.8 是历史上第一个突破 10% 的模型。法律、税务、合规这些行业, 第一次有了「能用 agent 跑严肃工作」的候选模型。

3 · Online-Mind2Web · 84%

浏览器操作基准跑到 84%。computer use 这条线一年里跳了一大段, 现在已经接近「替你操作网页」级别的可用。

4 · Terminal-Bench 2.1 + CursorBench 同步刷新

编程实测榜单 Terminal-Bench 2.1 + CursorBench 都被 4.8 刷了。Claude Code 用户体感会有明显提升。

5 · 价格不变 + Fast Mode 便宜 3×

Standard: 输入 $5 / 输出 $25 每百万 token。Fast Mode: $10 / $50。和 4.7 一样。Fast Mode 还是比上一代便宜 3 倍, 大批量 inference 更划算。

6 · 新功能 · 3 件

— Claude Code 的 dynamic workflows: 并行子 agent 处理大规模代码任务 (codebase 级别的 migration / refactor)

— claude.ai 的 effort control: 用户能在「想得深」和「跑得快」之间挑

— Messages API 的 system entries: 任务中途修改指令, 不会破坏 prompt cache

7 · 平台覆盖全部 · 模型 ID 直接用

claude.ai · Claude API · Claude Code · Anthropic Console — 所有方案 (含 Enterprise / Team / Max) 立刻可用。API 模型 ID 就叫 claude-opus-4-8。

更大的信号: 4.7 到 4.8 看起来是小版本号, 但 4 倍代码诚实 + Legal Agent 10% 破零 + 浏览器 84%, 三件加一起是「agent 进严肃工作」这条赛道的拐点。下半年企业级 agent 流程开始向法律、医疗、金融、运营这些方向迁移会加速。

P.S. Anthropic 同一天还宣布 $65B Series H, $965B 估值。资本和产品两条线同时往上推, 接下来一年里 Opus 4.X 这条线的迭代节奏值得盯紧。
