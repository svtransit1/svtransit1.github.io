先别急着转。今天(7 月 8 号)你的时间线大概被这类恐慌帖刷屏了——这事被夸大了,但也不是完全没影。我把官方文档翻了一遍,按大家最想问的几个问题捋一捋。

背景:Anthropic 六月初更新了隐私政策,7 月 8 号对个人版 Claude(Free/Pro/Max)正式生效,新增了一条身份验证,用的是第三方服务 Persona。传言就是从这儿冒出来的。

问:以后打开 Claude 就得先刷脸?

不是。官方帮助文档的原话是,你「可能在使用某些功能、常规平台完整性检查、或其他安全合规措施时」看到验证提示。翻成人话:特定功能、被标记的少数账号、或者风控检查才触发,不是人人每次都要验。大部分人可能一次都碰不上。

问:要交什么?

政府签发的带照片证件,可能还要一张实时自拍。

问:证件和脸是不是就进 Anthropic 库里了?

这条是被骂得最冤的。证件和自拍由 Persona 保管,不落在 Anthropic 自己的系统里;Anthropic 需要时(比如你申诉)能通过 Persona 查到验证记录,它管的是「过没过」这个结果。当然,换个第三方存不等于风险消失,只是保管的主体换了。

问:企业和 API 也要验吗?

不用。Team、Enterprise 这些企业版,还有直接用 API 的开发者,这次都不在名单里。

顺带一句,这两天的骂声其实混了两件事:一个是身份验证,另一个是 Fable 5 同期改成了按量计费。两件撞一块儿,火气就叠上来了。

老实讲,我不觉得该恐慌,但也不想帮它洗。别只盯着那张自拍——真正的看点是方向。前沿 AI 正在悄悄从「匿名 + 包月」往「绑身份 + 按量」挪。今天只是被标记的一小撮人,可政策措辞留得很宽(「某些功能」),范围往后会不会扩,没人给准话;政策也没写这些验证数据要留多久,已经有法律的人点名,这可能踩到生物识别隐私(BIPA)的线。

所以别被「Claude 要你的脸」这种标题牵着走,也别当没发生。噪音底下那个信号,才是真正的看点。
