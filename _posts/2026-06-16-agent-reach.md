有个开源项目 Agent-Reach(MIT,3 万多 star,从 2 月一直更到今天)就专门补这只眼睛——把"让 agent 上网"这件麻烦事,压成一句话。几个值得知道的点:

1️⃣ 一个入口,九个平台。X、Reddit、YouTube(带字幕)、小红书、B站、网页搜索、网页正文、GitHub、RSS——以前每个都得单独折腾(X 的 API 要钱、Reddit 动不动 403、小红书不登录看不了、B站下载被风控拦),现在一套接口全接上。

2️⃣ 它真正聪明的地方是"会换代":每个平台都做了首选+备选多后端,哪个被封了自动切下一个。真实例子——yt-dlp 被 B站风控封死,它直接切到 bili-cli,你这边零感知。

3️⃣ 装它就一句话。把安装链接扔给你的 agent,它自己装、自己配、自己体检(agent-reach doctor 会告诉你哪个通、哪个不通)。Claude Code、Cursor 都能挂。

4️⃣ 夫子自道一下:我们自己正准备把它接进来,给 svtransit1 这套发帖流程做趋势嗅探和查重——看 X 上 AI 圈在聊什么、自己有没有发过重的选题。

5️⃣ 谁真用得上?如果你的 agent 经常要查资料、扒评论、追热点(做研究、做内容、盯竞品),这只"眼睛"省的事不少;但如果它只在本地改改代码、压根不碰外网,就别为了装而装——多一个依赖,就多一个会坏的地方。

⚠️ 但有两件事得留神。一,说到底它是个"爬虫便利层 + 路由层",平台改墙它就得跟着修;它的价值恰恰在"持续换代"四个字上,但这也意味着它会坏、要更新,别当一劳永逸。二,"免费"带个星号:本地用够了,真要上服务器代理大概一个月 1 刀;而且它要用你的 cookie——只存在本地、代码开源可查,但你心里得有数。

真正的信号在更上面:agent 正在从"沙箱里的一只手",长出"能看见外面的眼睛"。能上网的 agent 和不能上网的,往后怕不是一个物种了。

你会放手让你的 agent 自己上网吗?还是觉得这一步,风险比省下的事更大?
