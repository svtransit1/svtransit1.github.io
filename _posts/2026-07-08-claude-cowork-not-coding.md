1️⃣ 它不再绑在桌面上了

以前 Cowork 只能在电脑上跑,这次 web 和手机都开了(还是 beta,先给 Max,几周内慢慢铺)。更关键的是任务能在后台跑:你合上电脑去开会,Claude 不会停,接着把活干完;桌面上起个任务,手机上就能看进度、点审批,回头在哪台设备上都能接着用,甚至断网也能拿到已经跑完的结果。等于把「AI 助理」从一张桌子,搬到了你走到哪带到哪。

2️⃣ 九成用户,根本不在写代码

这是我觉得最值得盯的一条。Anthropic 自己统计了 Cowork 的真实用量,结果超过 90% 跟软件开发无关(原话是「more than 90% wasn't software development」),用得最多的两大类是业务运营和内容创作。换句话说,在这个主打「agent 帮你干活」的产品里,程序员反而是少数派。

3️⃣ 它在真金白银地推

配合这次上线,Anthropic 把加倍的用量额度一路延到了 8 月 5 日,还专门拉了 Ramp 的客户成功负责人出来背书。摆明了是想趁这波把非技术用户圈进来、养成习惯——免费额度给够,等你用顺手了再谈钱。

一句话总结:大多数人一提 Claude,想到的都是终端里那个写代码的 agent、想到 Claude Code。但 Anthropic 自己的数据指向另一个方向——它真正想接的,是整个办公室里那些「不写代码」的活:排期、写材料、跑流程、盯项目。终端 agent 的热闹是真的,可这盘棋,人家下得比「让 AI 更会编程」大得多。对真在用 Claude 的人,这也是个信号:它下一步的更新重心,很可能往「非技术办公」那一侧倾;Claude Code 之外的战场,才是它眼下真正想抢的地盘。

泼盆冷水:这 90% 是 Anthropic 自报的用量、没有第三方审计;产品还在 beta、目前只给 Max;而且这本来就是篇产品公告,对自己有利的框架当然会挑着说。数字方向可信,具体比例听听就好。
