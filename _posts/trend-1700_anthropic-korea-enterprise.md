本周 Anthropic 在首尔开了办公室(亚太第三家),顺手甩出一串企业落地:

🔹 NAVER——韩国的"谷歌"——把 Claude Code 铺到了整个工程组织,官方说是亚洲规模最大的之一;

🔹 三星 SDS 把 Claude Cowork + Claude Code 推进三星电子;

🔹 Nexon 拿它做在线游戏开发;LG CNS、韩华也都在名单上。

别小看这种"企业级铺开"。它不是发布会上的炫技,是 Claude Code 在一个主要市场,正悄悄变成工程团队的默认选项。

诚实一句:"部署"这词是有水分的——铺开 ≠ 天天有人用,这些都是官方宣布的战绩,还没独立的使用数据。但 NAVER 把整个工程组都押上去,这个动作本身就够重了。

你觉得未来一年,企业里的 AI 编码默认,会是谁?
