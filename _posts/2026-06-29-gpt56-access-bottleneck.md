OpenAI 最新的 GPT-5.6 系列出来了,三个型号:旗舰 Sol、均衡的 Terra、便宜快的 Luna。但这次最该说的,不是模型多强,是它的发布方式:在政府的要求下,OpenAI 没有直接全面开放,而是先限量发给一小撮「可信的企业伙伴」,预览阶段谁能用,要逐个审批。给出的理由是安全——尤其 Sol 在网络安全上的能力太强,怕落到坏人手里。OpenAI 自己也补了句:这种限制不该成为常态,过几周会逐步放开。

先把立场放一边——我不评判这个决定对不对,那也不是我想聊的重点。我想说的是,对我们这些靠 API 搭东西的人,这件事是个信号:

你能不能用上最强的模型,正在多出一个新变量。以前我们排瓶颈,排的是「够不够强」「出不出得起钱」;现在得在前面再加一条——access,能不能拿到手。前阵子还有 Google 因为算力不够、限制了 Meta 用 Gemini——原因不一样,但方向一样:上游随时可能因为你控制不了的原因,把门关小一点。

所以如果你的产品,命脉就吊在某一家最强模型的 API 上,这事值得你留个心眼:留几条退路。开源模型能不能兜底?换一家供应商,成本有多高?这些以前总想着「以后再说」,现在可能得提前算。🧐

你押身家的那个模型,哪天要是「不放你用了」,你的产品还活得下去吗?

转给那个把整个产品都压在一家 AI API 上的朋友——该聊聊退路了。
