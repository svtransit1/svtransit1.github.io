过去比的是"谁更聪明"——榜单谁第一、谁的分数高出零点几。这一周你会发现,话题悄悄挪到了另一边:跑不跑得起、信不信得过、能不能真交付。我挑了五件事,单看都不算炸,但叠在一起,这条暗线特别清楚👇

「一,Bun 把自己从 Zig 重写成了 Rust,动手的是 AI」

这活是一个跑在 Claude Code 上的 agent harness 干的——一整支工程师团队的工作量,交给了它一个。作者 Jarred Sumner 说得很直白:他动的是流程那一层,代码本身基本交给 agent 自己写,整个过程大约十一天,烧了差不多十六万五千美金的 token,换来一百多万行新代码、Linux 启动快了约一成。但真正的功臣,是 Bun 那套差不多一百万条断言的 TypeScript 测试套件——agent 每改一版,拿它判分,过不了就重来。它才是重写的裁判。大改造能不能成,真正的胜负手是你手里有没有那套兜得住的测试,模型强不强反倒退居次要。多数遗留系统,恰恰就缺这一套。

「二,有人把 744B 的 GLM-5.2 塞进了 25G 的笔记本」

纯 C、零依赖,靠把绝大多数 experts 摊到硬盘上、用到哪个再流式读进来,落盘约 370GB,常驻内存只要 9.9GB。听着很燃。但速度是每秒 0.05 个 token——一个 token 要等二十秒,顶配的 M5 Max 也才每秒 1.06 个。它证明了"前沿模型能在消费级机器上跑起来",这是真本事;但"能跑"和"能用"之间,隔着一整个交互形态——你得把它当成寄信,而不是聊天。

「三,查毒的 AI agent,自己把毒运行了」

AI Now 研究院的 Friendly Fire 攻击:Claude Code、Codex 这类会自动执行命令的 agent,能被仓库 README 里一句"跑一下这个安全脚本"骗着,去执行它本该揪出来的恶意代码。最扎心的是门槛——不需要装任何插件、MCP 或自定义配置,开箱默认就中招,唯一前提是你开了 auto 自动批准模式。研究员给的建议冷得很直接:补丁救不了你,改工作流才行,先把自动批准关掉。而且这不是孤例——同一周还有个 GitLost,把 GitHub 的 AI agent 骗去泄露私有仓库。agent 被仓库里的内容牵着走,正在变成一类全新的攻击面。

「四,给 agent 装记忆,反而更省钱」

腾讯云开源的 TencentDB Agent Memory,一个跑在本地、零外部 API 的长期记忆层。在 WideSearch 任务上,token 用量砍了约 61%,成功率还从 33% 涨到 50%;SWE-bench 上 token 也省了三成多;记住你的偏好后,PersonaMem 准确率从 48% 跳到 76%。大多数人以为记得越多越贵,这东西把它反了过来——有了记忆,agent 不用每次把一切重读一遍,省下的是实打实的账单。

「五,连 Google 的旗舰都在为"跑得起"让路」

Gemini 3.5 Pro 一拖再拖,推到了 7 月中,有报道说架构整个重做了,定位却主打"更省钱的选择"。另一边,Anthropic 甩出加拿大 Alberta 省政府的案例:50 个 agent 并行,20 小时扫了 4.66 亿行代码。一个在为成本改架构,一个在秀规模——但提醒一句,那个 4.66 亿行其实是最不值钱的数字,真正有含金量的,是"5 个月的门户 4-5 天重建"这种交付,和那套红蓝对抗的审查工作流。两件事指的是同一个方向:能力已经是入场券,落地和成本,才是这一代真正的胜负手。

把这五件事叠在一起,这一周的味道就出来了:AI 圈集体从"够不够聪明"的问题,滑向了一个更实在的问题——它到底能不能在你手里稳稳跑起来、还交得出活。测试套件、token 账单、自动批准的开关、记忆层、交付时间——这些词,半年前还是工程师私下才聊的细节,现在成了发布会和融资故事的主角。对真在用 AI 干活的人来说,这其实是好消息:热闹褪去一点,大家终于开始认真聊那些你每天真会撞到的事了。

下周见。🧐
